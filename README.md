# Feladatok Android App

Ez egy egyszerű Android teendőkezelő alkalmazás (Kotlin, Jetpack Compose, Room DB).

## Használat GitHubon:
1. Csomagold ki ezt a ZIP-et.
2. Hozz létre egy új tárhelyet (repository) GitHubon.
3. Töltsd fel (push-old) a kicsomagolt fájlokat a fő ágra (`main`).
4. A GitHub Actions (`.github/workflows/build-apk.yml`) automatikusan elindítja a build folyamatot, és a végén letöltheted az elkészült `.apk` fájlt az Actions fülsor alatt az Artifacts szekcióból!
